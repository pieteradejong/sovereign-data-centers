# The book

Print edition of the EU-27 sovereign data centre model. Built with [typst][]; the interior
is mono by decision, the cover is colour.

[typst]: https://typst.app

```
./run.sh book                        # gazetteer + reference, compile to book/build/book.pdf
python3 book/build.py --part 3       # one part, for fast proofing
python3 book/build.py --typ-only     # emit the .typ without compiling
```

Requires `typst` (`brew install typst`). `init.sh` warns if it is missing.

## Structure

Per `DECISIONS.md` #27 — an authored argument plus a gazetteer, because at 73.5% mean
pairwise prose similarity the generated briefs would make an unreadable read-through book.
Reference sections are allowed to be formulaic; the argument has to live somewhere else.

| Part | Content | Source | Status |
|---|---|---|---|
| I | The argument | `manuscript/part-1-argument.typ` | **Scaffold** — spine only, ~10k words to write |
| II | The method | `manuscript/part-2-method.typ` | **Scaffold** — ~8k words to write |
| III | The twenty-seven (gazetteer) | generated by `build.py` | Working |
| IV | Reference tables | generated by `build.py` | Working |
| V | The federation finding | `manuscript/part-5-conclusion.typ` | **Scaffold** — ~6k words to write |

Parts I, II and V are authored directly in typst rather than markdown — typst's prose
markup is close enough to markdown (`=` headings, `*bold*`, `_italic_`) that a converter
would be a dependency for no gain.

## Where the numbers come from

`build.py` reads `web/public/data/eu27.json` — the same `country_data.build()` dict the
markdown briefs and the web app render from (`DECISIONS.md` #6). It recomputes nothing.
Regenerate the bundle with `./run.sh data` before building if the model has changed.

## Layout

```
manuscript/     authored parts (I, II, V)
templates/      style.typ — page setup, type scale, table styles
figures/        hand-made figures; generated charts come from the model
contacts/       named individuals — GITIGNORED, see DECISIONS.md #26
build/          book.typ and book.pdf — GITIGNORED, regenerable
```

## Conventions

- **Mono interior** (`DECISIONS.md` #28). No hue anywhere in `templates/style.typ` — `luma()`
  only. Briefing documents get photocopied, and mono print-on-demand is about a third the
  unit cost at ~300 pages. Any chart added here must survive grayscale by encoding value in
  texture or position, not colour.
- **Provenance on every page** (`DECISIONS.md` #25). The page footer carries the working-
  assumption disclaimer and the generation date. Do not remove it to gain a line.
- **Nothing generated is committed.** `build/` is gitignored. The build is deterministic
  given `.build-epoch`, so the PDF is always reproducible from source.
- **No named individuals**, here or anywhere in the repo outside `contacts/`.

## Before print

`DECISIONS.md` #25 gates publication: a printed book cannot be corrected after the fact.
The six legal columns in Part III are factual claims about real jurisdictions, a different
epistemic category from the scaled capacity figures, and the "working assumption" banner
does not cover them. Required before print:

- [ ] Tier-1 legal cells verified against primary sources
- [ ] Sampling audit with a measured error rate per column
- [ ] Corrections channel live and printed in the front matter
- [ ] Three country briefs read end to end
- [ ] Parts I, II and V actually written

## Known rough edges

- A5 with `breakable: false` tables leaves large white gaps where a table cannot fit the
  remaining page. Revisit once Parts I/II/V carry real text and the flow settles.
- No cover, no front matter beyond the half-title, no index, no bibliography.
- Part IV is a placeholder shape: the results table and the shared assumptions. What else
  belongs there is still open.
